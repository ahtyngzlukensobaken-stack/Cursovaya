# Учёт выданных и возвращённых товаров

Основная складская программа с регистрацией, входом по логину/почте и паролю,
общей базой товаров, получателей, выдач и возвратов.

Администратор управляет доступом сотрудников. Новая регистрация ожидает
подтверждения и не открывает доступ к данным склада. Сотрудники могут вести
обычные операции; полное восстановление и очистка доступны администратору.

Сервер выполняет все операции через Inventory, проверяет целостность данных,
даты, остатки, журнал возвратов и текущую ревизию. При конфликте одновременных
изменений операция отклоняется. Пароли хранятся как PBKDF2 с уникальной солью,
сеансы — как хеши случайных токенов. На GitHub Pages сеанс передаётся в
Authorization и хранится только в sessionStorage текущей вкладки. При открытии
приложения на домене сервера используется HttpOnly/Secure cookie.

Интерфейс работает на GitHub Pages без перенаправления. CORS разрешён только
для указанного в worker/app.mjs GitHub-origin и собственного origin сервера.
Адрес API задаётся в web/config.js. Пароли в статических файлах не хранятся.

## Проверка и сборка

`npm ci` — зависимости генератора миграций.
`npm run db:generate` — SQL из db/schema.js.
`npm run build` — Worker в dist/server/index.js.
`npm test` — серверные проверки на SQLite.
`node tests/browser.mjs` — вход, выдача, возврат, роли и общий склад в двух браузерах.

Публикация использует Sites с D1-привязкой DB. Миграции лежат в drizzle/.
Секреты начальной настройки ADMIN_SETUP_TOKEN_HASH и ADMIN_SETUP_EXPIRES
настраиваются в окружении. Начальная учётная запись создаётся один раз через
защищённую серверную операцию; пароли и исходный токен в репозитории отсутствуют.

Почта при регистрации не подтверждается: почтовый сервис восстановления пока
не подключён. Пароль можно сменить в разделе «Аккаунт».
