# Учёт выданных и возвращённых товаров

Курсовой проект: разработка и тестирование программы учёта выдачи и возврата товаров
(инструмента, оборудования, средств защиты) на складе или в пункте выдачи.

## Запуск программы

Установка не требуется. Откройте файл `index.html` в браузере (Google Chrome, Microsoft Edge,
Mozilla Firefox или Яндекс Браузер). Данные сохраняются автоматически в памяти браузера на этом компьютере.

Для знакомства с программой откройте вкладку **«Данные»** и нажмите
**«Загрузить демонстрационные данные»**.

## Возможности

- справочник товаров (артикул, наименование, единица измерения, категория, количество);
- справочник получателей (ФИО, подразделение, телефон);
- оформление выдачи со сроком возврата и контролем остатка на складе;
- оформление полного и частичного возврата; повреждённые единицы списываются;
- журнал операций с поиском и фильтрами (выдан, частично возвращён, возвращён, просрочен);
- оборотная ведомость за период и список задолженностей получателей;
- выгрузка журнала и ведомости в CSV (открывается в Excel);
- резервное копирование и восстановление данных (файл JSON) с проверкой целостности.

## Структура проекта

```
index.html                  главная страница (интерфейс)
css/style.css               оформление
js/validation.js            проверка входных данных
js/inventory.js             бизнес-логика учёта
js/storage.js               сохранение данных, резервные копии
js/app.js                   связь интерфейса с бизнес-логикой
tests/unit/                 модульные тесты (ТС-В, ТС-Т)
tests/integration/          интеграционные тесты (ТС-И) и тест масштабируемости (ТС-Н03)
tests/load/                 нагрузочные тесты (ТС-Н01, ТС-Н02)
tests/e2e/                  системные тесты интерфейса в браузере (ТС-С)
docs/test-logs/             протоколы прогона тестов
```

## Запуск тестов

Требуется Node.js версии 22 или новее.

```
npm test              # модульные, интеграционные и нагрузочные тесты (78 тестов)
npm run coverage      # те же тесты с измерением покрытия кода
npm install           # один раз — установка Playwright для тестов интерфейса
npx playwright install chromium
npm run test:e2e      # системные тесты интерфейса (13 тестов)
```

Итог последнего прогона: 91 тест, 91 успешный; покрытие модулей логики — 99 % строк,
92 % ветвлений, 100 % функций (см. `docs/test-logs`).
